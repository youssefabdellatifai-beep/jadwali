# جدولي — جدول الفرقة الثانية

موقع عربي لمحاضرات وسكاشن الفرقة الثانية، جامعة المنيا الأهلية.

## الملفات

- `index.html`: الصفحة وتنسيق الموقع الأساسي.
- `app.js`: الجدول، اختيار المجموعة والسكشن، البحث، التفاصيل، وعرض جميع مواعيد مادة واحدة.
- `data.js`: بيانات المواد الست والمواعيد.
- `courses.css`: تنسيق اختيار المواد.
- `print.js`: توليد محتوى الطباعة وملاءمته لورقة واحدة.
- `print.css`: تنسيق الطباعة والخلفية والألوان والتذييل.
- `timetable.pdf`: الجدول الأصلي المرتبط من الموقع.
- `.nojekyll`: تقديم الملفات مباشرة على GitHub Pages.

## التشغيل

افتح `index.html` في متصفح حديث، أو استخدم Live Server في VS Code.
لا يحتاج المشروع npm أو بناء أو قاعدة بيانات؛ هو HTML وCSS وJavaScript فقط.
الخطوط تُحمّل من Google Fonts وتحتاج اتصال إنترنت.
اختيارات المجموعة والسكشن تُحفظ محليًا في متصفح الزائر باستخدام localStorage.

## الرفع على GitHub

1. فك ضغط الملف.
2. أنشئ مستودعًا جديدًا على GitHub.
3. اختر Add file ثم Upload files وارفع محتويات المجلد بعد فك الضغط.
4. تأكد أن `index.html` في جذر المستودع، وليس داخل مجلد إضافي.
5. احفظ باستخدام Commit changes.

ارفع الملفات المفكوكة، وليس ZIP وحده.
إذا لم يظهر `.nojekyll` أثناء الرفع لأنه ملف مخفي، يمكنك إنشاؤه من GitHub أو رفعه باستخدام Git.

## تشغيل الموقع على GitHub Pages

1. من المستودع افتح Settings ثم Pages.
2. اختر Deploy from a branch، وفرع `main` ومجلد `/ (root)`، ثم احفظ.
3. انتظر اكتمال النشر؛ سيظهر رابط الموقع في قسم Pages.

الروابط الخاصة بملفات المشروع نسبية، فيعمل أيضًا داخل مسار مستودع GitHub Pages.

## الطباعة

اختَر المجموعة والسكشن، أو مادة واحدة، ثم اضغط طباعة وحدد الأسبوع أو يومًا.
استخدم A4 ومقياس 100%، وفعّل Background graphics وألغِ Headers and footers.
الكود يقيس المحتوى ويضبط حجمه ويثبت التذييل داخل الورقة.
اختُبرت الوظائف وتوليد بيانات الطباعة برمجيًا؛ يلزم مراجعة المعاينة في المتصفح المستخدم.

## تعديل المواعيد

عدّل المصفوفة في `data.js`:

- `day`: السبت 0، الأحد 1، الاثنين 2، الثلاثاء 3، الأربعاء 4.
- `slot`: 0 للفترة 09–11، و1 للفترة 11–13، و2 للفترة 13–15، و3 للفترة 15–17.
- `course`: net للشبكات، db لقواعد البيانات، oop، prog للبرمجة، os لنظم التشغيل، disc للتراكيب المتقطعة.
- `kind`: L للمحاضرة، S للسكشن.
- `group`: المجموعة كما وردت في المصدر.
- `sections`: أرقام السكاشن، وفارغة للمحاضرة.
- `room` و`teacher`: القاعة والمحاضر / المعيد.
- `id`: رقم فريد للموعد.

بعض خانات المصدر تجمع أكثر من نشاط دون تحديد وقت منفصل لكل نشاط أو توزيع مؤكد للقاعات والمعيدين.
